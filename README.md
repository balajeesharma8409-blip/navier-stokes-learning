Navier–Stokes Fluid Simulation

This is a beginner project I made while learning about fluid dynamics and the Navier–Stokes equations.

What this project does

The project uses Python to explore how fluid motion can be represented computationally.

I am learning how Newton's laws of motion, especially F = ma, lead to equations describing the motion of fluids.

What I am learning

- Fluid motion
- Newton's laws applied to fluids
- Navier–Stokes equations
- Numerical simulation
- Python programming

Note

This is a learning project and is not a solution to the Navier–Stokes Millennium Prize Problem.

Tools

- Python
- Google Colab
- NumPy
- Matplotlib
